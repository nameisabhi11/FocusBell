# 🔔 FocusBell

A simple and powerful browser alarm extension designed to help you stay on schedule and manage important tasks without leaving your browser.

FocusBell allows users to create alarms, receive browser notifications, play custom alarm sounds, snooze alarms, and manage recurring schedules through a clean and modern interface.

---

## ✨ Features

- ⏰ Create custom alarms
- 🔔 Browser/Windows notifications
- 🔊 Multiple alarm sounds
- 😴 Snooze alarms
- ❌ Dismiss alarms
- 🔁 Recurring alarms
  - Once
  - Every Day
  - Every Weekday
  - Every Week
- 🌙 Dark mode
- ⚙️ Customizable settings
- 🎵 Selectable alarm sounds
- ⏱️ Custom snooze duration
- 📝 Alarm history
- 🔄 Persistent alarms after browser restart
- 🛡️ Missed alarm detection
- 📱 Dedicated alarm popup window
- 🔘 Enable/Disable alarms
- 🗑️ Delete alarms
- 💾 Local storage — no account or login required
